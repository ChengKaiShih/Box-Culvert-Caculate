## 必須保留的限制

- §4.3/4.4 比較列出各頂板活載絕對彎矩峰值，非逐截面正負包絡選用，候選較小值未套用RC。不可宣稱該項全數完成。
- 未納入多車道、車道載重、邊緣板局部效應；淺覆土S採淨寬，不利用倒角縮短。
- 側壓作用於外牆中心線高度，外廓交接區等效仍須人工覆核。
- Winkler 雙向線性彈簧；Rigid Base 為底板節點垂直拘束，不是均勻基底反力。
- 剪力、裂縫、鋼筋細部、地下水／浮力、非線性接觸、完整組合庫仍未完成。
- 公開算例已整理來源及差異，但尚未宣稱全箱涵外部算例數值吻合。
