## 數值模型假設

- 毛斷面、線彈性，未開裂；不包含 Timoshenko 剪切變形。
- 板牆中心線模型之側壓高度採中心線高度；與實際外廓側壓及交接剛域的等效方式尚需設計者檢視。
- Rigid Base 與 Winkler 定義詳見 ARCHITECTURE.md。
- 未考慮水壓與浮力，不能用於有地下水工況的完成設計。
- 配筋需求比根據所輸入組合，不會把服務載重自動轉成強度設計載重。

## V3 新增分析依據（3.0.0-alpha.1）

- 內部靜水壓 IW：p=γw z，γw=9.80665 kN/m³；單側 P=γw Hw²/2、作用點距底 Hw/3，水平底板 q=γw Hw 向下。0≤Hw≤淨高，全滿仍屬自由水面非承壓流；不是地下水浮力。
- **倒角濕周水壓尚未獨立積分。** 採垂直牆面及水平底板矩形淨孔；驗證水重用 cells×淨寬×Hw，不使用含倒角實際水體面積。各孔同水深，隔牆兩側載重均建立後相加抵銷。
- 頂板彈性撓度：Euler–Bernoulli、毛斷面 Gross EI、一階線彈性、未考慮開裂。以 EI v″=M 積分，包括 member-load particular deformation；δ=v−支承中心線連線。向下值以正值 mm 報告。無 L/360、L/800 或其他 PASS/FAIL。
- 相對撓度極值解 δ′=0，而不是直接解未扣支承連線斜率的 v′=0。分段多項式以導數根隔離、二分求根；集中力及 patch 分區處理。彎矩極值仍由 V=0 分段解析二次方程取得。
- 端力表區分 Face Moment（柔性設計斷面）與 Joint Moment（剛接中心線）。RC 沿用柔性段同時 N–M 需求，不以 Joint Moment 替代 Face 需求。
- 本版不新增 RC 規範判定，不宣稱開裂撓度、長期變形或水密裂縫檢核完成。
