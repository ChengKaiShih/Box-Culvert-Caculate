## 官方來源

1. [交通部：公路橋梁設計規範](https://www.motc.gov.tw/ch/app/divpubreg_list/view?id=740&module=divpubreg&serno=424)：109-01-03，交技(109)字第1095000070號；附件包含 98 年本文與 104/109 年修訂。109 修訂公告針對 §1.1/§1.4。此版核對 98 本文第 3/4/6 章，104 修訂與全卷適用性尚待逐項核對。
2. [國土署：建築物混凝土結構設計規範](https://www.nlma.gov.tw/ch/legislation/regsearch/6874)：112-08-10 修正，113-01-01 生效；113-02-19 勘誤。採其 SI 公式作斷面試算，與橋梁設計體系之適用順序尚未完成整合。
3. [國土署：112 建築物基礎構造設計規範](https://www.nlma.gov.tw/uploads/files/53651dae74223e6599e20838bb8c4f2a.pdf)：列為後續地盤設計依據；Winkler ks 為使用者輸入，非由此規範自動查表。

## 數值模型假設

- 毛斷面、線彈性，未開裂；不包含 Timoshenko 剪切變形。
- 板牆中心線模型之側壓高度採中心線高度；與實際外廓側壓及交接剛域的等效方式尚需設計者檢視。
- Rigid Base 與 Winkler 定義詳見 ARCHITECTURE.md。
- 未考慮水壓與浮力，不能用於有地下水工況的完成設計。
- 配筋需求比根據所輸入組合，不會把服務載重自動轉成強度設計載重。
