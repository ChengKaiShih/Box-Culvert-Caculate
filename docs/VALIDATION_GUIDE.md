# V2 人工驗證指南與公開算例

查核：2026-10-06。這份指南提供可獨立核算的入口，不表示程式已通過外部計算書全項比對。先比載重，再比支承、剛域與內力，最後才比較配筋。

## 已讀到正文的官方案例

### 1. WisDOT：雙孔箱涵算例，建議先讀

- [官方章節目錄](https://wisconsindot.gov/Pages/doing-bus/eng-consultants/cnslt-rsrces/strct/bridge-manual.aspx)
- [Chapter 36 PDF](https://wisconsindot.gov/dtsdManuals/strct/manuals/bridge/ch36.pdf)
- 章節版面 July 2026；附件 E36-1 算例另標 July 2021、LRFD Ninth Edition 2020。不能把章節更新日期當作算例全數重算日期。
- PDF 第56頁（印刷36E1-2）起為雙孔幾何；第59～60頁為自重、土壓；第64頁起為分項靜載彎矩與剪力。搜尋 `E36-1.6.2`、`E36-1.6.3` 可定位。
- 每孔淨寬、淨高均12 ft（3.6576m）；頂板12.5 in（0.3175m），底板14 in（0.3556m），內外牆12 in（0.3048m）；覆土4 ft（1.2192m）。
- 適合核對：幾何、混凝土自重、載重分項、正負彎矩位置與控制工況整理方式。
- 不能直接宣稱同值：採AASHTO LRFD、HL-93等車載、靜止土壓及土壤互制修正，與本程式台灣車型、主動土壓自訂模式及支承有差異。不要將原文K0數值填入Ka欄後稱模型完全相同。

### 2. MnDOT：單孔預鑄箱涵教材

- [官方手冊入口](https://www.dot.state.mn.us/bridge/lrfd.html)
- [可讀取的2013年歷史第12章PDF](https://www.dot.state.mn.us/bridge/pdf/lrfdmanual/section12.pdf)
- 此連結正文頁首為 September 2013；官方入口目前另列較新的章節，兩者不可混稱最新版。
- PDF 第4頁（12-4）有分析模型與自重作用說明；§12.5 為10ft×10ft單孔算例；PDF第36頁表12.5.2為分項彎矩，第37頁為剪力及軸力表。
- 適合學習：載重拆分、底板反力、配筋檢核流程。
- 關鍵差異：教材採底角鉸／滾支承並搭配均佈向上地盤反力；本程式的Rigid Base不是這個模型，Winkler也不等於均佈反力。教材自重的轴壓效益與底板重處理亦不同。請先對齊條件，不能直接用其M值判斷本程式誤差。

## 第一輪：不用外部軟體即可驗證的預設模型

三孔、每孔淨寬3m、淨高2.5m、頂板0.35m、底板0.40m、外牆0.35m、中隔牆0.30m、倒角0.20m、混凝土24kN/m³。以下以1m分析帶、未乘係數計算。

| 檢查 | 人工計算 | 預期 |
|---|---|---:|
| 總外寬 | 3×3+2×0.30+2×0.35 | 10.30m |
| 頂板重 | 10.30×0.35×24 | 86.52kN |
| 底板重 | 10.30×0.40×24 | 98.88kN |
| 外牆重 | 2×0.35×2.5×24 | 42.00kN |
| 中隔牆重 | 2×0.30×2.5×24 | 36.00kN |
| 倒角重 | 3×4×0.20²÷2×24 | 5.76kN |
| 自重總和 | 上述五項相加 | 269.16kN |
| EV，h=0.8m | 18.85×0.8 | 15.08kPa |
| EV總力 | 15.08×10.30×1 | 155.324kN |
| DL=10kPa時總力 | 10×10.30×1 | 103.00kN |

操作：先選無車載，將組合只留下DC=1、其餘=0，執行手動分析。底板反力總和應為269.16kN，ΣFy近零。再分別只開EV、DL核對。DL不應在A1/A2產生任何直接水平載重，但剛架內力仍可能因頂板受力出現牆彎矩。

自訂土壓可取γ=20、Ka=0.3，等值側向單位重應為6kN/m³。程式牆中心線高度為2.875m，覆土0.8m時，頂端深度0.975m、底端3.85m，頂底壓力5.85／23.10kPa，每側合力41.615625kN；左右水平合力互相抵銷不代表各側沒有土壓。

## 第二輪：車載與數值求解

1. h=0.6m：應為集中力，S=3m、E=1.38m、I=20%。HS20×1.25的前輪為22.5kN，分配後每米帶為22.5×1.2÷1.38=19.565217kN；不能當成整個軸重45kN。
2. h=0.8m：擴散邊長1.4m；左右輪線距1.8m時尚未重疊。前輪含衝擊壓力22.5×1.1÷1.4²=12.627551kPa。
3. 單孔S=3m：h=3m仍不忽略，h>3m才同時滿足h>2.4、h>S。多孔以L（端牆內面間距）判斷。
4. 分割4→8、步距0.5→0.25分別比較，先固定其中一项。載重相同、反力守恆是必要條件，但不代表網格及移動車位已收斂。
5. 求解器獨立案例見tests/solver.test.ts、tests/v2.test.ts：6m簡支梁、距左2m的30kN集中力，反力20／10kN，最大彎矩40kN·m；集中點剪力兩側20／−10kN。

## 比對紀錄欄位

來源版本／頁碼、幾何、單位、剛域、支承、載重圖、組合係數、比較截面、正負號、參考M/N/V、程式M/N/V、差值與原因。若參考值接近零，使用絕對誤差；不要用相對百分比放大微小差值。

目前V2的§4.3／4.4表只比較各頂板LL最大絕對彎矩，未完成逐截面正負彎矩設計採用。RC仍使用未折減剛架需求；勿把候選較小值解讀為已套用的配筋彎矩。
